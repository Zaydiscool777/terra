--------------------------------------------------------
a platformer in haskell. learning that language rn
-------------------------------------------------------------
it is a simple red ball that can be moved with the arrow keys and also interacts with gravity and the floor. note that you may have issues moving the ball, since the engine detects keys in a way similar to a text editor.

How to run: it's an elf file, so on linux:
- go to [releases](https://github.com/Zaydiscool777/terra2/releases/tag/release1.0)
- download executable (https://github.com/Zaydiscool777/terra2/releases/download/release1.0/terra-exe)
- `chmod +x` the file
- `./[file]` the file
- Esc or close button to close
